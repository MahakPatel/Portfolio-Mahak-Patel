# Portfolio Website

A dynamic, futuristic portfolio website built with Go backend and React frontend.

## Features

- **Dynamic Content Management**: Admin dashboard to update portfolio content
- **Real-time GitHub Integration**: Automatically fetch and display GitHub projects
- **Modern UI**: Futuristic design with animations and responsive layout
- **Multiple Sections**: Home, Projects, Skills, Experience, Education, Publications, Contact
- **Social Media Integration**: Links to all social media accounts

## Tech Stack

### Backend
- **Go**: REST API server
- **PostgreSQL**: Database for dynamic content
- **GitHub API**: Real-time project data integration

### Frontend
- **React**: Modern UI framework
- **TypeScript**: Type-safe development
- **Tailwind CSS**: Utility-first CSS framework
- **Framer Motion**: Smooth animations
- **React Query**: Data fetching and caching

## Project Structure

```
portfolio/
├── backend/          # Go backend API
├── frontend/         # React frontend
├── database/         # Database migrations and schemas
├── docker/           # Docker configuration
└── docs/            # Documentation
```

## Getting Started

### Prerequisites
- Go 1.21+
- Node.js 18+
- PostgreSQL 14+
- Docker (optional)

### Development Setup

1. Clone the repository
2. Set up environment variables
3. Start the backend server
4. Start the frontend development server

## Deployment

The application is configured for deployment on modern cloud platforms with Docker support.
